New raw formats and cameras can only be supported once a full set of
samples exists. Please shoot the core set for your camera's maker.

<details>
<summary>Canon (CR3)</summary>

Before shooting, set the camera's
<a href="https://cam.start.canon/en/C006/manual/html/UG-09_Set-up_0300.html" target="_blank" rel="noopener">copyright info</a>
to "CC-0", so the samples can be used in all raw sample databases.

If your camera supports different shutter modes (mechanical, electronic),
shoot the core set twice: once with the mechanical and once with the
electronic shutter (the latter uses a reduced bit depth).

The core set consists of these shots:

- **RAW** mode: ISO 100, 800 and max. ISO (often labeled H or H1/H2)
- **CRAW** mode: ISO 100, 800 and max. ISO (often labeled H or H1/H2)

If your camera supports them, also add:

- **Burst** mode: ISO 100 with 3–5 frames at most (keep the size small)
- **Dual Pixel** mode: ISO 100, one shot with RAW and one with CRAW compression
- **HEIF** mode: ISO 100

</details>

<details>
<summary>Olympus / OM Digital Solutions (ORF)</summary>

- ISO 100
- If supported: ISO 100 in each high resolution mode (handheld, tripod, …)

</details>

<details>
<summary>Fujifilm (RAF)</summary>

If supported:

- **Uncompressed** mode: ISO 100
- **Lossless compressed** mode: ISO 100
- **Lossy compressed** mode: ISO 100

</details>

<details>
<summary>Panasonic (RW2)</summary>

- ISO 100 with every supported crop (1:1, 4:3, 3:2, 16:9)

</details>

<details>
<summary>Phase One / Leaf (IIQ)</summary>

If supported:

- **IIQ-L** mode: ISO 100
- **IIQ-S** mode: ISO 100
- **IIQ-Sv2** mode: ISO 100

</details>

<details>
<summary>Pentax (PEF/DNG)</summary>

If supported:

- **PEF** mode: ISO 100
- **DNG** mode: ISO 100
- PEF and DNG in high resolution / pixel shift mode

</details>

<details>
<summary>Nikon and Sony (NEF/ARW)</summary>

Every combination of bit depth and compression, plus all raw sizes:

- 12bit-compressed, 12bit-uncompressed, 12bit-lossless-compressed
- 14bit-compressed, 14bit-uncompressed, 14bit-lossless-compressed
- L (large), M (medium) and S (small) formats
- APS-C / S35 mode

</details>
