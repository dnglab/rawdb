**Every submission is reviewed.** Uploads go into a review queue and are
only published after a reviewer has checked them against the guidelines
below. Sets that don't conform are rejected, so please read this before
you shoot and upload.

### How to shoot

The scene must be shot in daylight and be properly exposed. The ideal
scene shows many colors, like a blue sky with white clouds, green grass
and flowers or trees. Some ideas:

- A landscape with trees and/or plants
- A fruit basket with bananas, grapes, etc.
- A street with colorful houses

Don't capture people, cars or any other private property.

**No color checker cards, please.** They don't work well for visual checks.

### File names

Give every file a descriptive name like `CANON_5DMK3_ISO_100.CR2`.
**Please don't upload files with camera default names like `IMG_0001.CR2`**.
