## About the licenses on this site

Each set on RawDB carries a license declared by the operator or
uploader. The chip next to the camera name shows the SPDX identifier
(or a short label) of that license.


### Attribution

Even when not legally required, please consider citing RawDB and the
original uploader when you publish work derived from these samples.
It keeps the catalogue healthy and helps new contributors find us.

### Reporting a licensing issue

If you believe a set's declared license is wrong, or that a file in a
set was uploaded without permission, please open an issue at the
project's repository so the operators can review and remove the
content if necessary.
